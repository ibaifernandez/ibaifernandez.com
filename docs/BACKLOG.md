# Backlog de Recuperación y Estrategia

## La Situación Actual (El "Gran Columpio")

Se cometió un error estratégico inicial: se trataron todas las páginas estáticas migradas del WordPress original como si fueran simples artículos de blog (convirtiéndolas a formato `.md`). Esto destruyó el diseño visual complejo (galerías, dos columnas, llamadas a la acción, acordeones, etc.) que tenían en Elementor.

**Resolución**: El formato `.md` debe ser **exclusivo para los artículos del blog**. Todas las páginas estáticas clave deben ser reconstruidas como **componentes nativos `.astro`** para poder replicar su diseño original.

**Sin embargo**, antes de lanzarnos a reconstruir páginas a lo loco, la prioridad absoluta es la **OPERACIÓN TACIRUPECA**: definir la estrategia comercial y el embudo de ventas.
